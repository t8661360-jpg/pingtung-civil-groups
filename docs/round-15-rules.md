### 合作社稅務個案 (15-1 ~ 15-3)

#### 15-1: coopAdvertisingTaxability
- **觸發詞**: 廣告費、收廣告費、登廣告、繳稅、營業稅
- **含合作社**: true
- **回答模式**: 無法確認 + 引導
- **規則**:
```
[本站無法確認] 廣告費稅務處理

合作社收廣告費是否需繳營業稅，涉及：
• 稅法：營業稅法、所得稅法
• 合作社類型：消費/生產/勞動/信用等各有不同
• 業務性質判定：業務收入 vs 其他收入

建議洽詢：
📞 財政部南區國稅局 0800-000-321
   說明：合作社類型、年度廣告費金額、性質
📋 請準備：合作社章程、決算報表、廣告合約
```
- **提交COMMIT**: 無 (待承辦確認)
- **優先級**: 🔴 高

#### 15-2: coopLoanToMemberTax
- **觸發詞**: 貸款、利息、借錢、社員貸、稅務、認列
- **含合作社**: true
- **回答模式**: 無法確認 + 引導
- **規則**:
```
[本站無法確認] 合作社貸款給社員的稅務處理

合作社向社員貸款，利息收入如何稅務認列，需要：
• 確認：合作社法第38條規定的「定期利息」
• 核實：理事會決議的利息率與計算方式
• 稅務判定：應納所得稅/營業稅

建議洽詢：
📞 國稅局：利息收入稅務認列標準
   屏東分稽處 0800-000-321
📞 合作社聯合社：貸款定價與稅務處理慣例
📋 建議尋求會計師協助稅務規劃
```
- **提交COMMIT**: 無 (待承辦確認)
- **優先級**: 🟡 中

#### 15-3: coopBankLoanProcedure
- **觸發詞**: 銀行借貸、融資、貸款程序、向銀行借、借錢
- **含合作社**: true
- **回答模式**: 無法確認 + 參考流程
- **規則**:
```
[本站無法確認] 合作社向銀行借貸的詳細程序

向銀行申請貸款涉及多方面，建議流程：
1️⃣ 理事會決議：決定借貸金額、用途、利率上限
2️⃣ 準備文件：
   • 理事會決議書 (正本+影本)
   • 最近期決算報表
   • 合作社章程
   • 代表人身份證明
3️⃣ 銀行審查：財務狀況、擔保品、還款能力
4️⃣ 簽約撥款：簽署貸款契約、撥款

建議洽詢：
📱 往來銀行融資部：具體貸款要件
📞 合作社聯合社：擔保方案、利率參考
📋 聯繫合作社聯合社，可協助介紹金融機構

*不同銀行要求可能不同，請提前詢問*
```
- **提交COMMIT**: 無 (待承辦確認)
- **優先級**: 🟡 中

#### 15-6: communityVsAssociationDifferences
- **觸發詞**: 社區協會差別、不一樣、有什麼不同、社區 vs 協會
- **含合作社**: false (社區特有)
- **回答模式**: 部分確認 + 部分缺失
- **規則**:
```
[部分規定確認] 社區發展協會 vs 一般協會的差別

✅ 明確不同：
  1️⃣ 理事長連任限制
     • 社區協會：不得連任（人民團體法第20條）
     • 一般協會：理事長得連任一次（第19條）
  
  2️⃣ 組織名稱格式
     • 社區協會：屏東縣○○鄉(鎮市)○○社區發展協會
     • 一般協會：無統一格式限制
  
  3️⃣ 受理單位
     • 社區協會：向所在地鄉鎮公所申請立案
     • 一般協會：向縣政府社會處申請立案
  
  4️⃣ 監管機構
     • 社區協會：鄉鎮公所 + 縣政府社會處
     • 一般協會：縣政府社會處

❓ 待確認（需社區發展工作綱要）：
  • 會員資格限制（里民或開放）？
  • 活動範圍限制（社區內或跨域）？
  • 財務補助等級差異？
  • 人事編制要求（需設社工嗎）？
  • 業務報告格式不同？

建議洽詢：
📋 社區發展工作綱要（中央/屏東縣版）
📍 所在地鄉鎮市公所社會課
   詢問：「社區協會有什麼特殊規定嗎？」
💡 參考資料：已立案社區協會的章程與規則

*本站知識庫不完整，建議諮詢鄉鎮公所取得最新規定*
```

## 📝 開發注意事項

### 規則型態分類

**A 型：完全無法確認** (15-1, 15-2, 15-3, 15-5)
- 回答標題：[本站無法確認]
- 內容：解釋涉及法規 + 建議洽詢單位+電話
- 格式：統一、簡潔、提供電話

**B 型：部分可確認** (15-4, 15-6)
- 回答標題：[部分規定確認]
- 內容：✅已確認項 + ❓待確認項 + 建議洽詢
- 格式：checkbox 視覺化、清單明確

**C 型：完全確認** (已有 14-1~14-12)
- 回答標題：[規定確認]
- 內容：直接答案 + 法規引註
- 格式：簡潔、權威

### 回答格式統一化

```markdown
[標題] 問題簡述

正文（3-4段）：
1. 現象說明
2. 涉及法規簡述
3. 建議洽詢

聯絡方式：
📍 單位名稱
📞 電話
📋 建議說明內容

*免責聲明*
```
