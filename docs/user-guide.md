## 🔍 搜尋技巧

### 基本搜尋
系統支持自然語言搜尋，輸入方式盡量自然即可。

#### ✅ 好的例子
```
我是新任理事長要做什麼
改選後多久要報縣府
監事會要怎麼檢查帳目
```

#### ❌ 避免
```
理事 (太短，易歧義)
一堆關鍵字堆在一起 (系統會自動理解上下文)
```

### 進階搜尋 - 上下文查詢
如果您想根據之前的問題繼續追問，系統會自動理解上下文。

#### 例子
```
第一個問題: 改選完要多久做帳
├─ 第二個問題: 那要報到哪裡
│  └─ 系統理解為: 決算報縣府期限
│
├─ 第三個問題: 那我要怎麼做
│  └─ 系統理解為: 新任理事長改選後要辦什麼事
│
└─ 第四個問題: 多久內要完成移交
   └─ 系統理解為: 新任理事長接手後 15 日內要完成移交
```

## 💬 反饋系統使用指南

### 何時提交反饋
- ❌ **誤答**: 系統給出的答案不正確或與法規不符
- ⚠️ **漏洞**: 應該回答的問題但系統沒有
- 📝 **表述**: 用詞不夠清楚或容易誤解
- 💡 **建議**: 功能改進或優化方向

### 如何提交反饋

#### 步驟 1：點擊反饋按鈕
在頁面右下角找到 **💬** 按鈕，點擊打開反饋表單

#### 步驟 2：選擇反饋類型
```
❌ 這個答案有誤/不相關
   └─ 用於答案明顯錯誤的情況

⚠️ 應該回答這個問題，但沒有
   └─ 用於系統找不到相應規則

📝 用詞不夠清楚/易誤解
   └─ 用於答案措辭改進

💡 改進建議或功能要求
   └─ 用於 UI/UX 或功能層面的建議
```

#### 步驟 3：填寫詳情
```
您提出的問題: 改選後多久要做帳
系統給出的答案: [自動填入，可編輯]
具體描述: 
  答案提到「年終前三個月」，但沒有提到改選後
  要立即辦理的 15 日移交期。新任理事長實際上
  需要知道改選後立即要做什麼事，而不只是決算
  期限。建議答案需要區分「立即要做」和「決算
  期限」兩部分。
```

#### 步驟 4：提交
點擊「提交反饋」，即完成提交 ✓

### 隱私保護
- 📍 **完全匿名** - 不收集任何個人信息
- 🔒 **本地存儲** - 反饋先存在您的裝置上
- ☁️ **加密同步** - 通過 HTTPS 安全傳輸到 GitHub
- 🗑️ **隨時清除** - 可在瀏覽器設定中清除 localStorage

## ❓ 常見問題 (FAQ)

### 搜尋相關

**Q: 系統找不到我的問題怎麼辦？**
A: 請嘗試：
1. 用更簡短的詞彙重新提問
2. 換個角度描述 (例如「誰來選」vs「怎麼選」)
3. 點擊右下角反饋按鈕提交「漏洞」反饋
4. 聯絡承辦部門 (見文末)

**Q: 為什麼同一個問題有不同答案？**
A: 這通常表示問題涉及多個規則：
- 先看最相關的答案
- 使用上下文查詢明確您的具體需求
- 如有歧義，提交反饋幫助改進

**Q: 我用繁體中文和簡體中文提問，答案會不同嗎？**
A: 系統僅支持繁體中文。請使用繁體中文提問。

### 反饋相關

**Q: 提交反饋後會發生什麼？**
A: 
1. 反饋自動保存到您的瀏覽器
2. 每天 11:00 (UTC+8) 時系統自動同步到 GitHub
3. 開發者會檢查並優先處理高頻問題
4. 通常在 24 小時內給出回應

**Q: 我的反饋會被公開嗎？**
A: 不會。反饋只用於系統改進，不會公開您的身份。

**Q: 反饋如果被採納會通知我嗎？**
A: 目前不會。但您可以定期檢查系統是否修正了問題。

### 法規相關

**Q: 這個系統覆蓋所有人民團體法規嗎？**
A: 不完全。系統主要覆蓋屏東縣常見的法規。
- 如需其他法規，請聯絡承辦部門
- 如果發現遺漏，請通過反饋告知

**Q: 我的協會有自己的章程，與系統說法不同怎麼辦？**
A: 系統說明的是**最低法定要求**。您的章程可以加強要求。
- 建議以章程為準
- 如有疑問，向主管機關(屏東縣社會處)確認

**Q: 這個系統的答案有法律效力嗎？**
A: 本系統**非官方解釋**，僅供參考。
- 重要決定建議洽詢承辦部門或律師
- 系統錯誤時，以法規原文為準

## 🛠️ 技術說明

### 系統環境需求
- 瀏覽器: Chrome、Firefox、Safari、Edge (最新版)
- 網路: 需要 Internet 連接
- 儲存空間: 約 1 MB (本地 localStorage)
- 無須安裝任何軟體

### 隱私與數據
- 所有數據在您的瀏覽器本地處理
- 只有反饋會發送到 GitHub (加密傳輸)
- 不使用 Cookie 追踪
- 可隨時清除所有本地數據

### 瀏覽器設定
如要清除本地存儲的反饋：

#### Chrome/Edge
```
Settings → Privacy and Security 
→ Clear browsing data 
→ Cookies and other site data
```

#### Firefox
```
Preferences → Privacy & Security 
→ Cookies and Site Data 
→ Clear Data
```

#### Safari
```
Safari → Preferences 
→ Privacy 
→ Manage Website Data 
→ Remove All
```
