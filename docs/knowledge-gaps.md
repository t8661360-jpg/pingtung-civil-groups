## 🔴 合作社個案 (涉稅務/金融 - 無法確認)

### 問題清單

#### 1. 收廣告費要繳營業稅嗎？
- **現象**: 合作社刊登廣告或其他團體刊登於合作社刊物
- **涉及法規**: 所得稅法、營業稅法
- **本站結論**: 無法確認
- **建議洽詢**: 
  - 財政部南區國稅局 (0800-000-321)
  - 合作社類型：消費/生產/勞動/信用等
  - 說明：收廣告費是否視為業務收入或其他收入
- **參考來源**: 輪12 試答「廣告費記帳」規則

#### 2. 貸款給社員的稅務處理
- **現象**: 合作社向社員貸款，利息收入如何認列
- **涉及法規**: 所得稅法、合作社法第38條(定期利息)
- **本站結論**: 無法確認
- **建議洽詢**:
  - 國稅局：利息收入稅務認列
  - 合作社理事會：章程規定的利息率
  - 會計師：稅務規劃
- **參考案例**: 消費合作社的貸款制度

#### 3. 向銀行借貸要辦什麼手續
- **現象**: 合作社急需資金，向銀行申請貸款的流程
- **涉及法規**: 銀行法、合作社法第53條(理事會決議)
- **本站結論**: 無法確認詳細程序
- **建議洽詢**:
  - 往來銀行融資部：合作社貸款要件
  - 合作社聯合社：貸款擔保方案
  - 理事會：決議授權書簽具
- **參考流程**: 
  1. 理事會決議借貸
  2. 準備財務報表、章程、決議書
  3. 銀行審查
  4. 簽約、撥款

### 標記方式

在應用中回答：
```
[合作社個案] 廣告費稅務：本站無法確認
因涉及營業稅、所得稅等稅務事項，不同合作社類型(消費/生產/勞動)
規定不同，請洽財政部南區國稅局 0800-000-321
```

## 🟡 社區發展協會專屬規定 (缺工作綱要 - 部分無法確認)

### 問題清單

#### 1. 要報公所哪些事項
- **現象**: 社區協會日常運作中，哪些事項必須報公所備查
- **涉及法規**: 社區發展工作綱要（**尚未取得全文**）
- **本站現況**: 只知道以下必報項目
  - ✓ 會員大會紀錄（30日內）- 人民團體會務輔導辦法第12條
  - ✓ 年度決算報告（3個月內）- 財務處理辦法第11條
  - ✗ 其他項目不確定（年度計畫？社務報告？）
- **建議洽詢**:
  - 所在鄉鎮市公所社會（民政）課
  - 屏東縣政府社會處
  - 各公所要求可能不同
- **參考來源**: 輪11 試答「社區協會要報公所」

#### 2. 年度計畫的送件期限
- **現象**: 社區協會應於何時提報年度工作計畫
- **涉及法規**: 社區發展工作綱要
- **本站結論**: 無法確認
- **建議洽詢**:
  - 所在鄉鎮市公所社會課
  - 區域發展協會或聯誼會
  - 同縣鄉鎮社區協會（互相詢問）
- **常見期限**: 
  - 12月底前提報下年度計畫(待確認)
  - 如有變動於3月底前補報(待確認)

#### 3. 與一般協會有什麼差別
- **現況**: 已有初步規則（輪10-13）
  - ✓ 理事長連任限制（不得連任）
  - ✓ 取名格式規定
  - ✓ 受理單位（鄉鎮公所 + 縣政府）
  - ✗ 其他差別（待確認）
- **可能差別**:
  - 會員資格（里民 vs 自由入會）
  - 活動範圍（社區內 vs 跨鄉鎮）
  - 財務規模（補助等級）
  - 人事編制（需設置社工？）
  - 業務報告格式
- **建議洽詢**:
  - 社區發展工作綱要（全文確認）
  - 公所社會課或社區發展中心
  - 已立案社區協會範例
