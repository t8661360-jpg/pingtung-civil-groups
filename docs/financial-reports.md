# 六項財務報表整理（持續任務）

> 依據：屏東縣政府社會處「團體會務」書表中的「6項財務報表.xlsx」（常年會、理監事會、改選資料夾均有收錄，內容一致）之「填寫說明」工作表、各表下方附註及表內公式。整理日期：2026-11-09。
> 適用範圍：一般協會（社會團體）。合作社、社區發展協會是否使用相同表式，**尚未確認**（見「缺口」）。
> 本文件不含任何範例金額。

## 一、名稱與檔案結構
| 項目 | 範本工作表 | 用途 |
|---|---|---|
| 收支預算表 | 預算 | 年度開始前編列收入、支出科目預算 |
| 收支決算表 | 決算與現金出納表（上半） | 年度實際收支，與預算比較 |
| 現金出納表 | 決算與現金出納表（同表） | 現金收支與結存；本期收入、支出由決算自動帶入 |
| 財產目錄 | 財產目錄 | 依財產登記簿逐筆列示固定資產 |
| 資產負債表 | 資產負債表 | 年度終了時資產、負債、基金暨餘絀 |
| 基金收支表 | 基金收支表 | 基金（如準備基金）收支與結存 |

Excel 只有 5 個表格工作表＋1 張填寫說明，因為決算表與現金出納表在同一工作表。解散時送的是不含預算表的 5 項。

## 二、逐表重點（官方填寫說明原意）
- **預算**：上年度結餘款不可列入今年收入；依收支平衡原則編列，本期餘絀需歸零；不適用科目可自行刪除。預算與決算科目名稱相同，改預算科目名稱，決算會自動修改。團體名稱只要在「預算」輸入，其餘工作表自動帶入。
- **決算與現金出納表**：本期餘絀＝收入總計－支出總計；累計餘絀＝本期餘絀＋上期餘絀。現金出納表本期收入、支出由決算「收入總計」「支出總計」自動帶入，決算正確則現金出納表即正確。
- **財產目錄**：依財產登記簿按固定資產科目編造；範本未設折舊，使用年限到期得依規定報廢；財產總金額須在資產負債表「固定資產」或「其他資產」呈現。須經製表、保管、會計、總幹事及團體負責人蓋章。
- **資產負債表**：流動資產＋基金＋固定資產＋其他資產＝資產合計；流動負債＋長期（固定）負債＋其他負債＋基金＋餘絀＝負債、基金暨餘絀合計；兩方合計須相同。範本內建檢核：兩方不等時顯示「兩方合計金額必須相同 請更正」；財產目錄合計不等於固定資產＋其他資產時顯示「財產金額不正確 請更正」。本期餘絀、上期餘絀由決算表帶入。有價證券、預付款項、短期借款、雜項負債等多數協會沒有；如已列入決算，勿重複填寫。須經製表、出納、會計、總幹事及團體負責人蓋章。
- **基金收支表**：基金應專戶儲存；如無基金，仍請核章後送府；有提撥基金會自動帶入資產負債表；動支基金應註明理事會通過之屆次與主管機關核備文號；各基金收支結存應與收支決算表及資產負債表相關科目一致。須經製表、出納、會計、總幹事、團體負責人蓋章。

## 二之一、編造與報送期限（現行規定）
依社會團體財務處理辦法第11條（111-11-28 修正；本站法規資料 2026-11-05 核對）：會計年度開始前由理事會編造年度工作計畫及收支預算表；會計年度終了後**三個月內**由理事會編造上年度工作報告、會計報告，連同當年度工作計畫、收支預算表，提經會員（會員代表）大會通過後，報請主管機關**備查**。未能如期開大會者，可先經理事會及監事會或理監事聯席會議通過，事後提報大會追認。決算金額達新臺幣 1,500 萬元以上得委請會計師簽證。
本縣社會團體章程草案範例第31、32條寫「年度開始前二個月編造、終了後二個月內編造、三月底前報核備」，與現行辦法不一致；網站已改以現行辦法回答並註明差異。**缺口**：縣府實際收件日期，需承辦人確認。

## 二之二、核章欄（依範本各表下方）
- 預算表、決算與現金出納表：製表、會計、總幹事、理事長。
- 財產目錄：製表、保管、會計、總幹事、團體負責人。
- 資產負債表、基金收支表：製表、出納、會計、總幹事、團體負責人。
其他相關規定：經費收入均應掣給正式收據並留存根；提用存款應由負責人、總幹事及財務人員共同蓋章（財務處理辦法第17條）；帳簿、憑證、報表於年度決算辦理終了後至少保存十年（第21條）；財務查核由監事會為之（第22條）。

## 三、數字關係（檢核順序）
1. 預算：本期餘絀＝0。
2. 決算：本期餘絀＝收入總計－支出總計 → 帶入資產負債表「本期餘絀」。
3. 現金出納表收支＝決算收支總計。
4. 財產目錄合計＝資產負債表固定資產＋其他資產。
5. 基金收支表結存＝資產負債表基金相關科目。
6. 資產合計＝負債、基金暨餘絀合計。

## 四、常見問題（已接入櫃檯）
資產負債表不平、沒有基金要不要交基金收支表、上年度結餘能否列入收入、財產目錄折舊、6 項是哪 6 項、報送期限、誰要蓋章、解散要送哪 5 項。

## 五、缺口（需使用者或承辦人提供）
- 合作社、社區發展協會年度決算使用的表式與名稱。
- 年度間是否有改版（本範本無年度標示）。
- 「社會團體財務處理辦法」現行條文與本範本科目對應的逐條核對（本站法規資料尚未收錄該辦法全文對照）。
