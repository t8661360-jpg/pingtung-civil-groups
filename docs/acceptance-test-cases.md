## 📋 測試用例編號系統

**格式**: `TC-[模塊]-[序號]-[優先級]`

例: `TC-SEARCH-01-P0` = 搜尋模塊、第 1 個用例、P0 優先級

**優先級定義**:
- **P0**: 核心功能，不過則無法上線
- **P1**: 重要功能，缺失會大幅影響體驗
- **P2**: 一般功能，中等重要性
- **P3**: 輔助功能，可接受延後

### TC-FEEDBACK-02-P0: 提交反饋 - 誤答類型

**前置條件**: 反饋按鈕可見

**測試步驟**:
1. 點擊反饋按鈕
2. 選擇類型: `❌ 這個答案有誤`
3. 在「您提出的問題」填入: `改選後多久要做帳`
4. 在「系統給出的答案」填入: `年終前完成` (故意錯誤)
5. 在「具體描述」填入: `這個答案不對，應該是年終前三個月`
6. 點擊「提交反饋」

**預期結果**:
- [ ] 表單顯示正常
- [ ] 可以填寫所有欄位
- [ ] 提交後顯示成功訊息
- [ ] localStorage 中檢查反饋已存儲

**驗證方式**:
打開瀏覽器開發者工具 (F12) → Console:
```javascript
JSON.parse(localStorage.getItem('feedbacks')).slice(-1)
```
應返回最新的反饋記錄。
