# 社團（職業團體）會務文件線上填報

依屏東縣政府社會處「貳-1.社團(職團)會務專區(非社區使用)」的範本整理，線上填寫會務文件，下載成 **Word（.docx）、Excel（.xlsx）或 PDF**。手機、電腦都能用。

👉 **線上使用：** https://t8661360-jpg.github.io/pingtung-civil-groups/forms/

## 選單（依縣府會務專區分類）

| 分組 | 選單 |
|---|---|
| 籌組與成立（依序辦理） | 籌備會 → 成立大會 |
| 改選年度（依序辦理） | 選前理監事會 → 會員大會－改選（含選後第一次理監事會） |
| 每年常會（依序辦理） | 大會前理監事會 → 會員大會－常年 |
| 其他會議與會務 | 理監事會（含會址變更）、會員大會－解散、其他會務（圖記印鑑證明、辭職書、證書補發、解散報告表） |

## 使用步驟：選文件 → 填資料 → 下載

- **會前、會後分開準備**：每個會議選單分成「① 會前：開會通知」與「② 會後：會議紀錄送件」，可以只選一批或兩批都選；第一次會依開會日期自動判斷。開會當天要用的簽到表、選票、委託書、大會手冊可在會前勾選產生。
- **必備自動勾選、選填才出現**：只有勾選的文件才會出現對應的填寫欄位與下載。手冊封面、會議議程、移交清冊為選填；會後的簽到表為選填，可上傳簽到後的照片或掃描檔。
- **團體名冊關鍵字帶入**：在首頁「先找到您的團體」或「團體基本資料」的團體名稱輸入關鍵字（團體名稱、理事長、電話或鄉鎮都可以，多個關鍵字用空白分開），會列出縣府人民團體名冊裡仍存續的團體；選擇後自動帶入團體名稱、會址、辦公電話、聯絡人（理事長）、立案字號、立案日期、目前屆別、每屆任期與上次改選日期，理事長也會加入理監事名單，全部都可以再修改，也可以按「復原」。名冊登記的任期已屆滿或快屆滿時會提醒改選。名冊資料讀取本 repo 的 `data/directory.json`（跟著名冊更新；已排除出生日期、住址、手機等個人資料）。
- **資料連動**：團體名稱、屆次、年度、人數、姓名、職稱、日期只填一次，自動帶入所有文件；選前會議填的工作計畫、財務報表、會員名冊會帶入會員大會手冊。
- **自動計算與檢查**：開會通知與會議紀錄送府期限、移交期限、出席是否過半、理監事名額、身分證字號檢查碼。
- **開會通知檢附資料**：開會通知書的報告事項或討論事項提到工作計畫、財務報表（決算、預算）、收支報告、會員名冊、理監事名冊、章程時，會前那一批自動勾選這些資料，通知書附註也自動列出附件；會後檢送會議紀錄時同樣會出現，兩批共用同一份資料，勾選則各自分開。
- **線上填寫或上傳檔案**：財務報表、預算表、工作計畫、收支報告、會員名冊、理監事名冊、章程等資料，每份都可選「線上填寫」或「上傳檔案」（Excel、PDF、Word、照片）；上傳模式也可下載範本，用 Excel 填好再上傳。
- **送件前自動檢查**：上傳的 Excel 會重新計算公式，找出公式結果沒更新、#DIV/0! 等錯誤值、手打合計與明細不符、資產負債表兩方不相等、收支餘絀不符；會員名冊檢查身分證字號檢查碼與重複、出生日期、人數與應出席人數；PDF 檢查頁數、加密與 A4 紙張；照片檢查解析度；Word 檢查還沒填的空白（○○○、＿＿＿）。線上填寫的資料也會檢查預算是否平衡、資產負債表是否相等、現金結存是否為負數，以及通知書提到卻沒附上的資料。下載頁最上方會列出全部錯誤與提醒。
- **名單匯入**：從 Excel 複製貼上，或直接選擇 .xlsx／.csv 檔（支援 Big5 編碼的 CSV）。
- **電子印章與簽名**：上傳蓋在白紙上的印章照片或掃描檔，自動切出每一顆章並去背；依簽章位置自動核章（團體圖記、職章、印鑑），可在預覽中拖曳、縮放、旋轉；也可以手寫簽名。Word、Excel、PDF 都會帶章。
- **附件上傳**：簽到後的簽到表、現行章程、身分證影本、權狀或稅單影本等，可上傳照片或 PDF，下載壓縮檔時一併附上；上傳的 PDF 與照片也會放進送件合併 PDF。
- **下載**：逐份下載、全部打包（.zip）、大會手冊合併、**送件合併 PDF**（檢核表＋全部文件＋上傳附件），以及送件檢核表。
- **電腦版／手機版版面**：依螢幕寬度自動切換。電腦版左右分欄：首頁選單與近期期限並列、選文件旁邊列出本次要準備的文件與期限、填資料旁邊即時預覽、下載頁旁邊是全部下載與期限。右上角可以切換手機版／電腦版，「⋯」裡可改回「自動」；手機選電腦版會像瀏覽器的「電腦版網站」一樣縮小顯示整頁。
- **操作提示（預設關閉）**：按右上角「?」開啟。滑鼠移到欄位或按鈕上（手機：點欄位、長按按鈕；鍵盤：Tab 移動）會顯示說明與即時提醒，例如開會日期會算出通知書與會議紀錄的送件期限、出席人數會檢查是否過半、身分證字號檢查碼、必填欄位、這一欄會帶入哪些文件；每個步驟上方也會有操作說明。可以在右上角或說明框上直接關閉。
- **期限提醒**：首頁顯示近期期限，可下載行事曆檔（.ics）加入手機行事曆。
- **存檔與換裝置**：自動存在瀏覽器；可備份成 .json 檔、分享備份檔到自己的信箱或雲端硬碟；管理者設定後，可登入 Google 帳號自動存到自己的雲端硬碟。

## 管理者設定：開啟「雲端存檔（Google 帳號）」

未設定時，網頁不會出現 Google 登入，其他功能都能正常使用。設定方式（免費，約 15 分鐘）：

1. 到 [Google Cloud Console](https://console.cloud.google.com/) 建立一個專案。
2. 在「API 和服務 → 程式庫」啟用 **Google Drive API**。
3. 設定 OAuth 同意畫面（Google Auth Platform）：
   - 品牌：填寫應用程式名稱（例如「屏東縣社團會務文件線上填報」）與聯絡信箱；授權網域加入 `t8661360-jpg.github.io`。
   - 資料存取：加入範圍 `https://www.googleapis.com/auth/drive.appdata`、`openid`、`email`（都屬於 Google 分類的「非敏感」範圍）。
   - 目標對象：使用者類型選「外部」，並將發布狀態改為「**實際運作中**」（測試狀態只有測試使用者能登入）。
4. 建立憑證 → **OAuth 用戶端 ID** → 應用程式類型「網頁應用程式」→ 已授權的 JavaScript 來源填 `https://t8661360-jpg.github.io`（不需要重新導向 URI）。
5. 複製用戶端 ID（`xxxx.apps.googleusercontent.com`），填入 [`forms/config.json`](config.json) 的 `googleClientId`，提交後約 1 分鐘生效。

## 隱私與個資

- 本網頁是純前端靜態頁面，**沒有後端伺服器**。填寫的資料（含身分證字號等個資）預設只存在使用者瀏覽器的 localStorage；電子印章與上傳的附件存在瀏覽器的 IndexedDB，都不會上傳。
- 登入 Google 帳號的雲端存檔，資料存在**使用者自己的 Google 雲端硬碟「應用程式資料」空間**（drive.appdata 範圍，只能存取本網站自己的資料，看不到使用者其他檔案），本網站與管理者都無法讀取。使用者可在 Google 帳戶的「第三方應用程式與服務」移除存取權，並在雲端硬碟「設定 → 管理應用程式」刪除隱藏的應用程式資料。電子印章預設不同步到雲端，上傳的附件不會同步。
- 「清除全部資料」會一併刪除瀏覽器中的印章與附件。請勿在公用電腦上傳印章。
- 下載檔案時，網頁會從 jsDelivr／cdnjs 載入開源函式庫（docx、ExcelJS、html2canvas、jsPDF、JSZip、pdf-lib）在瀏覽器內產生檔案；Google 登入時會載入 Google Identity Services。

## 修改程式

原始碼在 `src/`（每個模組一個檔案），修改後執行：

```bash
python3 forms/src/build.py
```

會重新產生 `forms/index.html`（單一檔案）。
