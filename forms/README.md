# 人民團體會務表單線上填報

協助社區發展協會等人民團體，線上填寫改選與年度會務表單，並下載成 **Word（.docx）、Excel（.xlsx）或 PDF**。

👉 **線上使用：** https://t8661360-jpg.github.io/pingtung-civil-groups/forms/

## 包含的表單

1. 理監事暨會務人員一覽表
2. 會員大會會議紀錄（含理監事選舉）
3. 理監事聯席會議紀錄
4. 申請理事長當選證明書填報資料
5. 會址使用同意書
6. 章程修正條文對照表
7. 年度工作計畫
8. 財務報表：收支預算表、收支決算表及現金出納表、財產目錄、資產負債表、基金收支表
9. 送件公函

每份表單可單獨下載，也可在「基本資料」頁把全部表單合併成一個檔案下載。

## 欄位連動

- 團體名稱、屆別、年度會帶入所有表單的抬頭、會議案由、財務報表期間與公函。
- 「理監事暨會務人員一覽表」是人員主檔：理事長、理監事、總幹事、會計、出納會自動帶入會議紀錄、當選證明、同意書、簽章欄等。
- 會員大會選舉輸入得票數後，會依票數排出當選與候補名單，並可一鍵更新到一覽表。
- 財務報表：預算與決算共用科目；決算餘絀帶入資產負債表；財產目錄金額帶入固定資產；並自動檢核預算是否平衡、資產負債表兩方是否相等。

標示「連動」的欄位留白時會自動帶入，直接輸入即可覆寫，按「↺ 還原」改回自動帶入。

## 隱私

本網頁是純前端的靜態頁面，**沒有後端伺服器**。填寫的資料（包括身分證字號等）只儲存在使用者自己瀏覽器的 localStorage，不會上傳。換電腦或交接時，請用「備份資料」存成 .json 檔，再用「還原資料」載入。

下載 Word／Excel／PDF 時，網頁會從 jsDelivr／cdnjs 載入產生檔案用的開源函式庫（docx、ExcelJS、html2canvas、jsPDF），檔案在瀏覽器內產生。

## 修改程式

原始碼在 `src/`，修改後執行：

```bash
python3 forms/src/build.py
```

會重新產生 `forms/index.html`（單一檔案，可直接用瀏覽器開啟）。

## 聲明

本工具為協助填報之輔助網頁，非政府機關官方網站；表單格式參考屏東縣人民團體範本，實際送件格式與規定以主管機關公告為準。
